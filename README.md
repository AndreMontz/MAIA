# MAIA

Portal experimental de acessibilidade do Centro de Piracicaba.

Site: https://andremontz.github.io/MAIA/

Frontend estático publicado nesta branch. Backend, banco de dados e imagens privadas rodam no PC responsável, acessado por túnel HTTPS gratuito. O PC e o túnel precisam permanecer ligados.

Para atualizar o endereço do túnel, edite apenas maia-config.js e aguarde o GitHub Pages publicar. Nunca inclua senhas, tokens ou chaves nesse arquivo.

As ocorrências da demonstração são fictícias. Rotas são experimentais. Cartografia © OpenStreetMap contributors, ODbL (geo/README.md).
