# MAIA

Mapa de rotas acessíveis do Centro de Piracicaba, com registro de barreiras pela população e painel de gestão para o órgão responsável.

Site: https://andremontz.github.io/MAIA/

Esta branch contém somente o frontend estático. O backend, o banco de dados e as imagens ficam numa VM na Azure; `maia-config.js` aponta para essa API. Nunca inclua senhas, tokens ou chaves nesse arquivo.

Os exemplos marcados como simulados (SIM-) são fictícios. Calçadas e rebaixamentos são inferidos e devem ser conferidos no local. Cartografia © OpenStreetMap contributors, ODbL (geo/README.md).
